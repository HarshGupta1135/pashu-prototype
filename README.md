# Pashu — Practo for Animals (MVP approach)

Screening assignment submission: a searchable, location-based platform for
India's animal-care ecosystem, built around one bet — *discovery is the hook,
the pet health record is the product.*

- **[Clickable prototype](https://harshgupta1135.github.io/pashu-prototype/)** — 6 screens: search, results, provider profile, AI prescription scan, health timeline, emergency mode.
- **[2-page write-up](https://harshgupta1135.github.io/pashu-prototype/explanation.html)** — product concept, user flow, 4 AI workflows, Next.js + Spring Boot architecture, 30-day build vs. cut list.

Hand-written HTML/CSS/vanilla JS, no framework. All clinics, doctors, NGOs,
records and figures are invented sample data for an illustrative Bengaluru
pilot and do not represent any real organisation or animal.
